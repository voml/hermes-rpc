# @yydb/hermes-unknown-wasm32

Hermes WASM fallback for browsers and WASI runtimes.

Provides a pure-WASM build of the Hermes RPC runtime that works in environments where native N-API binaries are not available (browsers, Deno, Bun with WASI, edge runtimes).

## Usage

This package is pulled in automatically by `@yydb/hermes` as the default fallback. It can also be imported directly.
